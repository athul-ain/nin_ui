## 0.1.0

* Add Material 3 predictive back transitions for dialogs, bottom sheets, and
  open containers.
* Add dynamic border radius and margin support for expanded list tile cards.
* Expand `NinUiScaffold` with navigation rail support and refine FAB positioning.
* Add One UI theming and platform brand detection, including support for
  non-native platforms.
* Use the split `material_ui` and `cupertino_ui` packages and remove unused
  dependencies.
* **Breaking:** Remove `ConnectivityIconButton` from the public API and remove
  the `connectivity_plus` dependency.
